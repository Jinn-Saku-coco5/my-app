## JiNN's Metronome (Rhythm Box)

自作のメトロノームアプリです！スマホやPCのブラウザから、ダウンロード不要で今すぐお試しできます。

## 🚀 今すぐブラウザで使う（お試しURL）
[https://github.io/my-app/](https://jinn-saku-coco5.github.io/my-app/)

## 💾 よしじゃぁ自分のPC（ローカル環境）に保存して使いたい場合
1. 下記のURLにパソコンのブラウザでアクセスしてください。
https://github.io/JiNNメトロノーム-配布v5.6.html

2. 画面が開いたら、キーボードの「 **Ctrl + S** 」を押すと、あなたのパソコンにそのまま保存（ダウンロード）して一生使えます。
